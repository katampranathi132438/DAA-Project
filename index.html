Breadth-First Search (BFS)

BFS explores the graph level by level. It visits the start node, then all of its neighbours, then their neighbours, and so on. It uses a queue (First In, First Out).

Depth-First Search (DFS)

DFS goes as deep as possible along one path before backtracking. It uses a stack (Last In, First Out), which is the same idea as recursion.
